Что такое JavaScript?

JavaScript — язык программирования, который позволяет добавлять на сайт динамику: обрабатывать нажатия, проверять формы, менять содержимое и работать с данными.

Учебная программа

Основные темы

Раскройте интересующую тему, чтобы прочитать краткое описание.

Для объявления переменных обычно используют let и const. Часто встречающиеся типы: string (строка), number (число), boolean (логическое значение), object (объект) и другие.

Условные конструкции if...else позволяют выбирать действия в зависимости от условия. Циклы for и while повторяют блок кода, пока выполняется заданное условие.

Функция объединяет инструкции в отдельный блок. События, например click или input, позволяют выполнять код в ответ на действия пользователя.

DOM представляет HTML-документ в виде дерева объектов. Метод document.querySelector() помогает найти элемент, а свойство textContent — изменить его текст.

О проекте

Сайт создан как учебный проект на тему «Скрипты JavaScript» с использованием фреймворка Bootstrap 5.3.3.

Цель проекта — показать, как с помощью JavaScript можно делать веб-страницы интерактивными: обрабатывать действия пользователя, менять содержимое страницы без перезагрузки и проверять введённые данные.

Что реализовано на странице

  • навигационная панель с адаптивным «бургер-меню»;
  • карусель со слайдами об основных темах JavaScript;
  • раскрывающийся аккордеон с учебной программой;
  • таблица с популярными конструкциями языка;
  • форма приветствия — обрабатывает имя и выводит результат;
  • мини-викторина с проверкой правильного ответа;
  • модальное окно, которое вы сейчас читаете.

Проект свёрстан с использованием сетки Bootstrap и адаптирован под разные размеры экранов. Собственные стили вынесены в css/style.css, а скрипты — в js/script.js.

При проверке работы обратите внимание на интерактивные элементы в разделе «Практика»: форму приветствия и мини-викторину.
